Two Sum (Problem 1)

LeetCode Easy Problem

Home / LeetCode Solutions / Arrays and Strings / Two Sum

Problem Description

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

Example 1:

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

Example 2:

Input: nums = [3,2,4], target = 6
Output: [1,2]

Example 3:

Input: nums = [3,3], target = 6
Output: [0,1]

Constraints:

  • 2 <= nums.length <= 104
  • -109 <= nums[i] <= 109
  • -109 <= target <= 109
  • Only one valid answer exists.

Solution

Approach 1: Brute Force

class Solution:
    def twoSum(self, nums, target):
        """
        Time Complexity: O(n^2)
        Space Complexity: O(1)
        """
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []  # No solution found

Approach 2: Hash Table (Optimized)

class Solution:
    def twoSum(self, nums, target):
        """
        Time Complexity: O(n)
        Space Complexity: O(n)
        """
        num_map = {}  # value -> index
        
        for i, num in enumerate(nums):
            complement = target - num
            if complement in num_map:
                return [num_map[complement], i]
            num_map[num] = i
            
        return []  # No solution found

Explanation

The optimized solution uses a hash table to store the numbers we've seen so far and their indices. For each number, we calculate its complement (target - current number) and check if it exists in our hash table. If it does, we've found our pair and return their indices.

Time and Space Complexity

  • Time Complexity: O(n) where n is the length of the array. We only need to traverse the array once.
  • Space Complexity: O(n) for storing the hash table in the worst case.
