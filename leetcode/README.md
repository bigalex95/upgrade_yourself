# LeetCode Solutions

A collection of my solutions to various LeetCode problems.

## Structure

This repository is organized by problem categories:

- **LeetCode 75/**: Solutions to the curated list of top 75 LeetCode questions
- **arrays_strings/**: Problems involving arrays, strings, and related algorithms
- **linked_lists/**: Problems involving linked list data structures
- **trees_graphs/**: Problems involving trees, graphs, and related algorithms
- **dynamic_programming/**: Problems solved using dynamic programming techniques
- **sorting_searching/**: Problems involving sorting and searching algorithms
- **machine_learning/**: Problems related to machine learning concepts

Each solution includes:

- Problem description and link
- Solution implementation in Python
- Test cases to verify the solution
- Time and space complexity analysis

## Getting Started

1. Navigate to a specific problem category
2. Choose a problem solution
3. Run the solution with: `python problem_name.py`

## Template Usage

To create a new solution file:

1. Copy the `template.py` file
2. Fill in the problem details and solution
3. Implement test cases
4. Add the solution to the appropriate category folder
