## Deep Learning for Computer Vision with Python and TensorFlow

**Instructor:** Folefac Martins (Neuralearn.ai)

### Key Topics Covered

- **Tensors & TensorFlow Basics:**
  - Tensors, variables, initialization, indexing, math & linear algebra operations, ragged/sparse/string tensors.
- **Neural Networks:**
  - Building, training, and evaluating models for regression and classification.
- **Convolutional Neural Networks (CNNs):**
  - Data prep, visualization, ConvNet theory, building/testing CNNs, saving/loading models.
- **Advanced Architectures:**
  - Functional API, model subclassing, custom layers, evaluation metrics (precision, recall, confusion matrix, ROC).
- **Model Performance:**
  - Callbacks, learning rate scheduling, checkpointing, overfitting/underfitting mitigation.
- **Data Augmentation:**
  - tf.image, Keras layers, Mixup, CutMix, Albumentations.
- **TensorFlow Advanced:**
  - Custom loss/metrics, eager vs graph, custom training loops.
- **TensorBoard & MLOps:**
  - Logging, graph visualization, hyperparameter tuning, experiment tracking (Weights & Biases).
- **Projects:**
  - Human emotions detection, modern CNNs (AlexNet, VGG, ResNet, MobileNet, EfficientNet), transfer learning, Grad-CAM.
- **Vision Transformers & Deployment:**
  - ViT, HuggingFace ViT, ONNX/TFLite/quantization, FastAPI deployment.
- **Object Detection & Image Generation:**
  - YOLO, VAEs, GANs.
